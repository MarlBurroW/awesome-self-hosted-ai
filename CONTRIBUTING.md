# Contributing to Awesome Self-Hosted AI

Thanks for helping keep this list accurate and useful.

## How to Add a Tool

1. **Fork** this repo and create a branch: `add-toolname`
2. **Add your entry** in the appropriate category
3. **Format** for OSS tools: `| [Tool Name](URL) | Description | License | [GitHub](gh-url) |`
4. **Format** for providers: `| [Provider](URL) | Best For | Starting Price | Notes |`
5. **Open a Pull Request** with the title: `Add ToolName to [Category]`

## Quality Standards

- **OSS tools**: must have a public GitHub repo with a commit within the last 6 months
- **Pricing**: GPU pricing changes constantly — note when pricing was verified if you know
- **Honest descriptions**: include limitations, not just features
- **No affiliate links** — plain links only

## What Not to Add

- Proprietary cloud-only AI tools (this list is for self-hosted)
- Tools that haven't been updated in over a year without explanation
- Duplicate entries (check carefully — many tools overlap categories)
- Your own project without disclosure

## Reporting Issues

Open an issue if:
- A tool is abandoned or deprecated
- GPU/VPS pricing is significantly out of date
- A provider has changed its offering materially
